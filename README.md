# Vangyan (apu)

Adivasi Rights & Empowerment Portal. An independent academic demonstration built with React, Vite, and Lucide icons.

[Open the live app](https://mrduhlol.github.io/vangyan-apu/)

## What you can do

- Read about individual, community, and community forest resource rights under FRA 2006.
- Filter illustrative scheme entries by category and audience. Verify eligibility and current terms with the linked official providers.
- Prepare notes for Form A, B, or C and print a Rule 13 evidence checklist. This app does not file claims or store notes on a server.

## Run locally

Requires Node.js 22 and npm.

```sh
npm ci
npm run dev
```

Open the localhost URL printed by Vite. To build for production, run `npm run build`.

## Deployment

GitHub Actions builds and publishes the app to GitHub Pages after pushes to `main`. The live link becomes available when the deployment succeeds.
